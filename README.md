# [ProtoripoDark3]

> Esse projeto tem como objetivo criar uma nova interação para jogadores de *match-3* (ligue 3), combinando a resolução de quebra-cabeças com mecânicas de sobrevivência e uma atmosfera de mistério.

## 🧩 Sobre o Projeto

## 🕹️ Mecânicas Principais

* **Match-3 Tático:** As combinações no tabuleiro geram recursos diretos para o personagem (ex: vida, munição, oxigênio).
* **Sobrevivência:** Gerenciamento de status do personagem enquanto o tempo passa ou os turnos acabam.
* **Atmosfera de Mistério:** Narrativa revelada aos poucos através da exploração e da conclusão de níveis específicos.

## 🛠️ Tecnologias e Ferramentas

* **Motor Gráfico:** Unity
* **Linguagem:** C#]
* **Design de UI/UX:** Adobe Illustraitor/Photoshop
* **Modelagem 3D / Arte:** Blender

# Tech Demo Controls & Info

The 3D scene for the tech demo can be found in **ArtTechDemo** (Folder) → **TechDemo** (Scene).

In this scene you can walk around as a placeholder Doomguy, fall in two traps, and move the camera around which culls any walls that would obstruct the view to the player.

## Controls

| Key | Action |
|-----|--------|
| `W` `A` `S` `D` | Camera Movement |
| `←` `→` Arrow Keys | Make Character Face Left or Right |
| `Space` | Make Character Walk Forwards |
